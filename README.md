# Orbis

Jeux de géographie, de culture générale, de picross et de langues, pour Android, 100 % hors ligne.

Ce dépôt sert à distribuer les versions de l'appli :

- `version.json` indique la dernière version et le lien de son APK ; le bouton « Rechercher une mise à jour » de l'appli le lit ;
- `releases/` contient les APK.

## Installer

Télécharge le dernier APK dans `releases/`, ouvre-le sur ton téléphone et autorise l'installation quand Android le demande. Une nouvelle version s'installe par-dessus l'ancienne sans perdre la progression.
